We dont need all ros2 topics (drop lidar, ego state, etc...)

We need only this 4 topics. Apply when using simulation

/carla/ego_vehicle/rgb/image/compressed                     -> Model input
/carla/ego_vehicle/segmentation/image/compressed            -> Ground-truth label
/carla/ego_vehicle/rgb/camera_info                          -> Intrinsics (metadata and calibration parameters for a simulated RGB camera attached to your main vehicle)
/carla/weather                                              -> Weather
